## Your Task:
Identify distinct workflow segments based on:
- Page or URL changes in the action data
- Functional areas (e.g., Login, Product Listing, Shopping Cart, Checkout, Confirmation, Logout)
- Natural boundaries in the user journey

For each segment provide:
1. A clear segment name reflecting its purpose (e.g., "Login", "Product Inventory", "Shopping Cart", "Checkout Information", "Order Confirmation")
2. A brief description of what this segment covers
3. ALL the action lines that belong to this segment — copy them exactly as-is, no modifications, no omissions
4. A list of keywords that identify relevant screenshot images for this segment (use words from the page name, URL path, or UI elements on that page)

## Critical Rules:
- Every action line must appear in exactly ONE segment — no line may be skipped or duplicated
- Preserve the exact original text of every action line
- Keep related actions together (same page/URL = same segment)
- If the entire recording is on a single page, return a single segment containing all lines
- Do not invent actions that are not in the input

## Output Format:
Return ONLY a valid JSON array. No markdown fences, no explanations, no extra text before or after the JSON.
