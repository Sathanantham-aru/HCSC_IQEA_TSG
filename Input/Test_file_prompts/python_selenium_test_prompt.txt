=== SECTION 0: BANNED PATTERNS (READ BEFORE GENERATING ANYTHING) ===
These are hard prohibitions. Violating any of these will produce a broken script.
❌ NEVER use a page-shell element (header, nav bar, cart icon) as the
   post-login readiness signal in do_login or any login helper.
   Shell elements load before the page content hydrates and will return
   clickable=True while product/content buttons are still non-reactive.

   WRONG:  safe_get(lambda: inventory.get_shopping_cart_link())
   CORRECT: safe_get(lambda: inventory.get_add_to_cart_<first_product>())

   The readiness signal must be an element that ONLY exists after the
   primary page content (product list, form, table) is fully loaded.
❌ NEVER wrap a function definition inside `with allure.step(...):` at module level.
   allure.step as a context manager executes at import time when placed at module scope.
   This crashes the entire test suite before a single test runs.

   WRONG:
   with allure.step("creating helper"):
       def my_helper(driver):
           ...

   CORRECT:
   def my_helper(driver):
       with allure.step("using helper"):
           ...

❌ NEVER call switch_to_new_window() as the first step in a test before navigate().
   There is only one window handle at startup. Calling it before any navigation
   causes immediate RuntimeError on every test.

❌ NEVER use `with allure.step(...)` as a context manager outside of a test function
   or fixture. Only use it inside def test_... or def fixture functions.

❌ NEVER hardcode scope="session" on the driver fixture. Always use scope="function".
❌ NEVER pass a bare POM method reference to safe_send_keys or safe_click.
   Always wrap in a zero-argument lambda.

   WRONG:  safe_send_keys(driver, pom.get_username_input, "text")
   CORRECT: safe_send_keys(driver, lambda: pom.get_username_input(), "text")

❌ NEVER use dispatchEvent in the JS fallback inside safe_send_keys.
   Use ONLY: driver.execute_script("arguments[0].value = arguments[1];", elem, text)
   Re-fetch the element fresh via getter_callable() immediately before this JS call.

    deadline = time.time() + timeout

        if len(driver.window_handles) > 1:
