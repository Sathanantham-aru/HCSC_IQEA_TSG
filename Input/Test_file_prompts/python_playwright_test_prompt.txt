--- RULE-WAIT: mandatory wait before every interaction ---

  Every POM class must contain this method exactly:

    def wait_for_element(self, locator_key: str):
        locator = getattr(self, locator_key)
        locator.wait_for(state="visible")
        return locator

  Call wait_for_element before EVERY .click() and EVERY .fill().
  Omitting this call is a generation error.

--- RULE-NAV: navigation waits ---

  After every page.goto() or navigation-triggering action:
    page.wait_for_load_state("networkidle")

  time.sleep() is permitted in TWO cases only:
    1. Inside RULE-HEAL retry blocks (0.5 sec)
    2. After save/submit actions that trigger a full page reload (1–2 sec)
  Do NOT add sleeps for any other reason.

--- RULE-POPUP: window and new tab handling ---

  Every "Switched to new window" line in recorded_actions generates this block:

    with allure.step("Handle popup / new tab"):
        try:
            with page.expect_popup() as popup_info:
                <trigger click action>
            new_page = popup_info.value
            new_page.bring_to_front()
            new_page.wait_for_load_state("networkidle")
            allure.attach(new_page.screenshot(), name="after_popup_open",
                          attachment_type=allure.attachment_type.PNG)
        except PlaywrightTimeoutError:
            pages = page.context.pages
            if len(pages) > 1:
                new_page = pages[-1]
                new_page.bring_to_front()
                new_page.wait_for_load_state("networkidle")
            else:
                new_page = page

    # Always re-instantiate ALL POM classes on the new page immediately after:
    <pom> = <ClassName>(new_page)

  Hard rules:
    - NEVER call new_page.goto() after switching to a popup
    - NEVER reuse old POM instances after a tab/window switch
    - NEVER switch window after page.goto()
    - ALWAYS recreate POM instances on the new page
